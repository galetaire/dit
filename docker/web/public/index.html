Set up your devices

Pick the setup that matches your network. Addresses are filled in from your Umbrel.

Whole home network (router)

Recommended

Every device on your Wi-Fi uses Dit, with nothing to change on each one.

  1. Give your Umbrel a fixed address in your router (often called "DHCP reservation" or "static lease"), so it does not change.
  2. In the router's DHCP or LAN settings, set the DNS server to your Umbrel's IP. Leave the secondary DNS empty: a second server would answer some lookups without Handshake.
  3. Reconnect your devices to Wi-Fi so they pick up the new setting.

Needs the "DNS server for my network" mode. If your Umbrel is off, devices lose DNS until it is back or you undo the router setting.

Android phone

Use the router setup, or set one Wi-Fi network by hand.

  1. At home: follow the router setup, or set it for one Wi-Fi network: Settings → Network & internet → Internet → your network → edit → Advanced → IP settings: Static, and enter your Umbrel's IP as DNS 1.
  2. Settings → Network & internet → Private DNS must be Off or Automatic. A provider name there (for example dns.google) bypasses Dit.
  3. In Chrome: Settings → Privacy and security → Use secure DNS → Use your current service provider, or turn it off.
  4. Away from home: use the Tailscale setup. Android has no DNS setting for mobile data.

Open Handshake names in the browser with a trailing slash, for example mysite/, so the browser does not search for them instead.

Anywhere, with Tailscale

Your devices use Dit on any network, without opening ports on your router.

  1. Install the Tailscale app on your Umbrel and on your phone or laptop, and sign in to the same account.
  2. In the Tailscale admin console, open DNS → Nameservers → Add nameserver → Custom, and enter your Umbrel's Tailscale IP (100.x.y.z).
  3. Turn on Override DNS servers.
  4. With Tailscale connected, the device resolves Handshake names through your Umbrel wherever it is.

Needs the "DNS server for my network" mode: Tailscale nameservers always use port 53.

Behind Pi-hole

  1. Choose "Upstream for Pi-hole or AdGuard Home" in Listening mode.
  2. In Pi-hole: Settings → DNS → untick the listed upstream servers, and add the custom server 127.0.0.1#5300.
  3. Untick "Use DNSSEC": Pi-hole checks answers against the regular internet's root key and rejects Handshake names. Dit already validates them.
  4. Untick "Never forward non-FQDN A and AAAA queries", so bare names like mysite/ reach Dit.
  5. Save. Pi-hole keeps blocking ads and sends every lookup to Dit.

Behind AdGuard Home

  1. Choose "Upstream for Pi-hole or AdGuard Home" in Listening mode.
  2. In AdGuard Home: Settings → DNS settings → Upstream DNS servers, replace the list with 127.0.0.1:5300.
  3. Apply. AdGuard Home keeps filtering and sends every lookup to Dit.
Never forward port 53 Don't forward port 53 from your router to your Umbrel. A resolver open to the internet gets abused for attacks on others.

Listening mode

Only one app on your Umbrel can use the standard DNS port (53). Pi-hole and AdGuard Home use it too.
